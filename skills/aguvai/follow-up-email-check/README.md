# follow-up-email-check

Install this skill from amdahl.ai, whichever way suits you:

- **Ask your agent.** Open https://amdahl.ai/skills/aguvai/follow-up-email-check and hand your agent the prompt there.
- **Download the file.** Save https://amdahl.ai/skills/aguvai/follow-up-email-check.md as `SKILL.md` in a folder named `follow-up-email-check`,
  in your agent's skills folder (`~/.claude/skills/` for Claude Code).
- **Use a terminal.** Run `npx amdahl skills add aguvai/follow-up-email-check`.

This folder is a copy of the skill, kept by the hourly mirror. `SKILL.md` has the same bytes
amdahl.ai serves. The mirror writes this README; it is not part of the skill.
